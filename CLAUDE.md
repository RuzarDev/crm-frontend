# Zircon — фронт

Платформа таможенного оформления в Казахстане (не «CRM»): кабинеты брокера, декларанта и клиента. Живой прод с реальными клиентами: zircon.kz.
Vue 3, TypeScript, Pinia, Tailwind v4, Reka UI, vue-i18n. Парный репозиторий — `RuzarDev/crm-server`.

## Как устроено
- Экраны — `src/views`, общие компоненты интерфейса `Z*` — `src/components/z`, запросы — `src/api`.
- Новый интерфейс собирается из `Z*`, цвета и размеры берутся из токенов `--z-*`. Ant Design удалён, возвращать нельзя.
- Эталон паттернов — транзит и пакеты документов; импорт выравнивать под них.
- Языки KK/RU/EN: `src/i18n/locales`, инструмент `scripts/i18n_tool.py`. Ключи данных реестра не переводить.

## Команды
- Типы: `npx vue-tsc --noEmit`.
- Тесты только целевые: `npx vitest run <путь к spec>`.
- Dev-сервер: `npm run dev -- --port 5200`, либо `preview_start` с именем `crm-frontend`.

## Никогда
- `npm test` целиком без разрешения владельца: ноутбук перегревается. Не больше 2 тяжёлых агентов сразу.
- Выкладка в обход `deploy/deploy-prod.sh`, сборка из папки с чужой незаконченной работой.
- Force-push и правки в main напрямую при параллельной работе: новая ветка или worktree.
- Секреты в коде, тема брендинга «тёмно-синий со свечением», буква Z в знаке.
- Тихое отсутствие очищенной графы: в PUT ДТ `null` очищает значение, а пропущенное поле не меняет его.

## Готово значит
1. `vue-tsc --noEmit` без ошибок.
2. Спеки затронутых файлов зелёные, и в отчёте указано, какие именно запускались.
3. Видимое изменение проверено в браузере: страница открывается, в консоли нет ошибок, нужное действие работает.
4. Новые подписи есть на всех трёх языках.
5. Экран работает на ширине телефона, где им пользуется клиент.
